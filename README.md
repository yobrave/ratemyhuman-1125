# Rate My Human

 One-Line Review:The one-line review an AI agent leaves about its human on a rating site. Builder emits it and checks the 200-character gate. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
